## 验收范围

- 任务从创建到确认、求解与结果展示；修改条件后撤销旧确认，重新建模与比较方案。
- 完整的约束、边界、整数域和目标值独立数值检查。
- 不可行问题不输出虚假目标或决策建议。
- 模型内容变更、过期与重复确认被阻止。
- 实际技能目录检索、模型筛选失败时的明确降级，以及产品对旧研究包的依赖检查。
- 工作台总览、任务流程、模型页、结果页、记录页、技能库与能力说明的渲染与导航。
- 交付包排除历史结果、原始数据、环境与凭据。

## 验证命令

```powershell
python run_experiment.py --workbench-test
python run_experiment.py --smoke-test
python run_experiment.py --method all --dry_run
```

最后一条是兼容别名，现执行实际业务模板的本地求解检查，不再调用已移除的科研基线。检查使用临时数据库，不在产品主页预填验收任务。

工作环境已验证 Python 3.10、Streamlit、CVXPY 与 SciPy / HiGHS 的兼容路径。实时模型服务依赖有效连接与额度；单个案例连通不代表覆盖所有问题、模型供应商或完整知识路由质量。

## 当前边界

不支持非线性模型、云端多用户协作与生产级隔离；没有完成目标用户访谈、可用性对照研究或商业收益评估。原文引用检查保证文字存在，不证明数学转换正确。
