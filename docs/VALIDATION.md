## 可以复现的业务样本

| 样本 | 求解结果 |
| --- | --- |
| 工厂生产计划 | A=100，B=200，总利润=10,000 元 |
| 工厂新增 A <= 100 | 数量和利润不变，原方案满足新增限制 |
| 工厂新增 A <= 80 | A=80，B=210，总利润=9,500 元 |
| 工厂新增 A >= 500 | Infeasible，不生成可执行建议 |
| 营销预算分配 | 预计有效线索目标值=195 |
| 客服人力排班 | 每日成本目标值=2,900 元 |

这些数字来自内置案例计算。求解器状态与数值检查用于判断当前模型的计算结果，用户确认用于记录业务复核。

## 上线后的首轮体验

我邀请了 15 位用户体验上线后的 Demo。反馈汇总中，自动建模与调整功能好评率约为 90%，业务范围相关的差评率为 40%；90% 为约数，两项评价对应不同功能。

本轮评价让我将场景扩展列为下一轮重点。用户还反馈了字号、操作顺序和入口不清楚等问题，对应调整见 [体验重构](UX-REDESIGN.md) 与 [产品决策](PRODUCT-DECISIONS.md)。

公开仓库只展示反馈汇总，不包含参与者身份和原始回答。目前没有前后对照的完成率、建模准确率、效率提升或企业收益结论。
