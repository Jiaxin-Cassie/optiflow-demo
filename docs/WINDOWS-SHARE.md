# Windows 电脑外网测试入口

不需要先购买服务器。当前 Windows 电脑运行平台，通过 Cloudflare Quick Tunnel 提供临时 HTTPS 地址；异地参与者用浏览器访问。电脑承担服务器角色，任务和问卷统一写入本机 `runtime/tasks.sqlite3`。

## 开启、查看和停止

1. 双击项目根目录的 `启动外网测试.cmd`，保持启动窗口运行。首次下载官方 cloudflared，并核对发布的 SHA-256；本机已下载并校验。
2. 等待连接完成，再双击 `查看外网入口.cmd`。打开的本地页面提供本次后台地址；入口状态也保存在 `runtime/share/connection.json`。
3. 后台口令位于本机 `runtime/share/后台口令.txt`。系统自动生成并限制文件访问权限，不放入交付包，不在聊天、命令行参数或日志中输出。请勿把这个文件发给参与者。
4. 登录后台，在“参与者邀请”选择案例并创建邀请，立即下载链接 CSV，给每个人发送各自的链接。公共首页不能直接开始测试。
5. 在“全量数据与导出”导出全部已开始的测试、操作与问卷；不需要参与者逐一发回文件。
6. 测试结束双击 `停止外网测试.cmd`。它只停止本项目启动器持有的平台和隧道进程，不删除数据库，也不停止其他本地工作台。

如果入口已在后台运行，不必重复启动。“查看外网入口”现在会检查最近心跳与公网健康接口，只在通过后打开本次后台，不会直接打开上一次的失效地址。停止、重启电脑或更换网络后，请重新确认连接状态。

所有功能也可通过统一入口调用：

```powershell
.venv-workbench/Scripts/python.exe run_experiment.py --share
.venv-workbench/Scripts/python.exe run_experiment.py --share-status
.venv-workbench/Scripts/python.exe run_experiment.py --share-open
.venv-workbench/Scripts/python.exe run_experiment.py --share-stop
```

## 地址与数据

- 临时域名每次重新启动会变化；旧邀请可将域名替换为新域名，保留完整 `?invite=...` 部分继续访问原记录。请向参与者发送更新后的完整链接。丢失邀请令牌时需要在后台撤销旧邀请并新建。
- 关闭睡眠、保持电脑联网，并让启动服务持续运行；锁屏不等于关闭服务。后台运行时不需要一直打开浏览器。
- 使用完入口后可以停止服务。重开仍使用原数据库、原邀请权限和原后台口令，已提交记录不会因为临时地址变化而删除。
- 受邀测试只开放三个内置业务案例，真实执行本机求解器。参与者看不到其他人的任务、管理员汇总或实时建模 API 配置。
- 不需要在路由器映射端口；平台仅监听本机回环地址，外网通过隧道访问。保留 Streamlit CORS 和 XSRF 保护。
- 入口就绪前分别检查本机与公网健康接口；公网浏览器的页面和登录仍应在发送邀请前检查。不同地区网络的可达性需要参与者实际确认。

Cloudflare 将 Quick Tunnel 定位为开发测试用途，无可用性保证，随机临时域名不适合长期固定发布。服务限制与说明见 [Cloudflare 官方文档](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。后续需要固定域名和长期运行时，使用账号下的命名隧道或按[在线部署指南](ONLINE-STUDY.md)迁移到服务器。

## 无法连接时

运行 `--share-status` 查看状态。`ready` 代表启动检查通过且有近期进程心跳；`unresponsive` 表示就绪记录已超过 30 秒未更新，不能当作服务仍在运行。`connecting` 代表仍在连接，`error` 有简短原因。诊断日志在同目录 `tunnel.log`、`server.log`，不包含后台口令。连不上隧道时检查当前网络是否允许 Cloudflare Tunnel 的出站连接，再停止并重试。

Windows 短暂占用状态文件时，JSON 写入会有界重试；心跳记录持续写入失败也不会再关闭运行中的平台和隧道。监控文件会在之后继续尝试更新。该处理避免因状态记录错误主动中断服务，但不能消除停电、休眠、网络故障或临时隧道本身的中断。

本机数据需要你自行备份；临时访问入口不是云端数据备份。导出 CSV 可以用于分析，完整迁移还应保留 SQLite 数据库及关联运行文件。
