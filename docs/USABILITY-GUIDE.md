# 如何收集、提取和删除可用性测试数据

异地参与者应访问同一在线实例：管理员创建专属邀请并统一导出，参与者只可查看自己的测试。部署方式见 [在线测试与后台](ONLINE-STUDY.md)。下述本机入口仍供本地操作使用。

**新版体验**：后台新邀请默认选择“新版工作台 + 独立体验反馈”。参与者先体验四阶段产品流程，之后自愿填写容易上手程度、下一步清晰度、困惑环节、操作问题与改进建议。反馈不影响模型或求解，可在任意阶段进入，再返回继续。见[新版设计与验收](UX-REDESIGN.md)。

**原 Word 手册测试**：历史邀请沿用原六任务协议。仍需组织同一测试队列时，在创建邀请时明确选择“历史手册流程”。步骤、三道访谈题和观察表见[手册测试说明](MANUAL-STUDY.md)。历史数据不改写，后台按协议与来源分别统计。

管理员在“全量数据与导出”点击“导出全部协议原始记录 CSV”获得全部参与者数据；也可以先按协议和记录来源筛选，再导出当前组。V2 字段包括 ease、clarity、confusing_stage、had_problem、problem、improvement 和反馈时的模型版本；历史字段继续保留。

## 从哪里收集

异地参与者打开自己的专属邀请，点击“开始体验”，依次描述需求、确认规则、检查模型和查看方案。匿名编号自动分配，不需要真实姓名、电话或账号。本机体验从产品导引进入，可选择内置案例或实时建模。

新版参与者查看有效结果后点击“完成体验，填写反馈”才记录完成；离开页面或只提交问卷不自动标记完成。任何阶段都可用“记录界面体验问题”进入独立反馈页，提交后继续工作台。历史六任务的记录方式见手册说明。

重新打开同一邀请会恢复自己的任务。下一轮测试应由后台创建新的专属邀请；不要多人共用一条邀请。本机体验和受邀体验分开统计，历史未标注来源的记录单独保留。

## 从哪里导出

**测试管理后台 → 全量数据与导出 → 导出全部协议原始记录 CSV**。本机也可从“历史任务与专业工具 → 任务记录与 Badcase → 可用性测试汇总”查看。

每行是一条参与记录，包含匿名编号、案例、任务 ID 与版本、开始和结束时间、测试状态、完成耗时、审核耗时、是否确认 / 反馈、人工标签、问卷提交状态、理解程度、困难环节和开放意见。时间字段采用 ISO UTC；页面任务时间显示北京时间。

测试结束时会固定记录当时的模型版本。此后即使继续修订业务任务，也不会把旧测试的评价错误归到新版本。

审核耗时从首次进入模型确认页计时，到首次有效确认；未确认但已经结束，则计到结束时间。仍在审核或尚未进入审核的记录不当成 0 秒。目标值和求解状态来自原业务任务，不在 CSV 中另行编造。

CSV 使用带 BOM 的 UTF-8，可在 Excel 中打开；自由文本包含公式起始字符时添加保护前缀。页面统计和导出使用相同的记录集合，少量数据同时显示实际分子和分母。

## 数据在什么位置

本机模式默认保存在项目目录 **runtime/tasks.sqlite3**。如果启动时使用 `--workbench-db PATH`，则保存在指定数据库中。在线部署模式将所有参与者数据保存在服务器同一个持久数据库中，由管理员统一提取；它不依赖参与者各自导出文件。

- `usability_tests`：匿名参与记录、开始 / 结束、预定义错误核查标准、人工标签和问卷。
- `events`：原任务事件与测试行为事件；测试事件包含测试 ID、匿名编号、案例、模型版本和时间，不重复保存业务原文。
- `usability_event_keys`：按测试、事件、模型版本去重，避免刷新重复。
- `tasks`：原业务任务、确认、模型和结果。
- `study_manual_sessions`、`study_manual_steps`：六任务版本、背景、开始时间、各步回答及经过时间。
- `study_observations`：管理员填写的观察完成情况、实测耗时、问题与复盘。

优先使用页面导出。单个业务任务的 JSON 与 Markdown 在 **查看方案 → 查看历史版本、前后对比与导出** 下载。旧普通任务没有采集到的匿名编号或问卷，不会被自动补造。

## 如何判断“错误发现”

测试设计者在测试开始前可以填写核查标准。系统不会自动向模板植入错误；参与者提交反馈，只代表提交了意见。设计者需根据标准和实际反馈，手动标记“正确发现 / 未发现 / 误报 / 未评定”。

没有预定义标准，或尚无人工评定时，不显示错误发现率。有评定时，分母只包含有标准且已评定的记录，页面同时显示实际计数；不能与全部参与记录的反馈率混用。

## 如何删除

在汇总区展开 **测试设计者：人工评定与数据删除**，选择记录，勾选明确删除范围后点击“删除测试数据”。

删除该专用测试的匿名记录、问卷、事件和对应任务的 trace、代码、日志，不影响普通任务。仍在后台建模或求解时不允许删除，需等待阶段结束。数据库与文件删除不是云端备份销毁机制，已自行导出的 CSV 需要自行管理。

当前尚未开展真实业务用户实验。开发验收模拟记录只能用于验证功能，不能作为完成率提升、用户理解度或商业效果结论。
